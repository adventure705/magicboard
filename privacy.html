Magic Board 개인정보 안내

이 페이지는 Google Sheets에 기록된 개인용 관측 데이터를 읽는 정적 대시보드입니다.

Google 로그인과 접근 범위

시트 소유자가 허용한 Google 계정으로 로그인하며, Google Sheets 읽기 전용 권한만 요청합니다. 시트 공유 설정을 변경하거나 데이터를 수정하지 않습니다. 다른 Google 계정의 로그인 비밀번호는 이 앱이 받지 않습니다.

데이터 처리

조회 요청은 브라우저에서 Google Sheets API로 직접 전송됩니다. 접근 토큰과 조회 데이터는 현재 탭의 메모리에만 유지됩니다. 앱은 이를 GitHub 저장소, 브라우저 저장소, 별도 서버 또는 분석 도구에 저장·전송하지 않습니다. 즐겨찾기 핀의 샵 ID만 현재 브라우저 설정에 저장됩니다.

로그아웃하거나 로그인이 만료되면 화면 데이터와 앱이 가진 메모리 참조를 지웁니다. Google 계정 자체에서 로그아웃하는 기능은 아니므로 공용 기기에서는 Google 계정도 별도로 로그아웃하세요.

호스팅과 외부 서비스

GitHub Pages는 정적 페이지 파일을, Google은 로그인과 시트 응답을 제공합니다. Google 로그인 도구와 글꼴을 불러오기 위한 일반적인 외부 요청이 발생할 수 있으나 이 요청에 관측·메모 내용은 포함하지 않습니다. 각 서비스의 자체 요청 로그와 정책은 해당 서비스가 관리합니다.

권한 철회와 삭제

로그아웃으로 현재 탭의 조회를 종료할 수 있습니다. Google 계정의 연결된 앱 설정에서 권한을 철회할 수도 있습니다. 원본 기록은 시트 소유자가 Google Sheets에서 관리합니다. 이 앱에는 별도의 데이터베이스가 없습니다.

문의는 저장소 문의를 이용하세요. 공개 문의에는 비공개 관측·메모·계정 정보를 첨부하지 마세요.
