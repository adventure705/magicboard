# Magic Board · GitHub Pages

Google 로그인 후 비공개 Google Sheets를 읽는 개인용 대시보드입니다. 편집·선택 삭제·되돌리기는 비공개 시트에 저장됩니다.

## 사용
- 게시된 GitHub Pages 주소를 열고, 시트 열람 권한이 있는 Google 계정으로 로그인합니다.
- 다른 컴퓨터나 휴대폰에서도 같은 주소와 계정으로 이용할 수 있습니다.
- 현재는 시트 소유 계정만 로그인 허용 목록에 있습니다. 계정을 추가하려면 Google Cloud 테스트 사용자와 시트 열람 권한을 둘 다 추가해야 합니다.
- 화면이 열려 있는 동안 약 60초마다 신규 기록을 확인합니다. 과거 기록도 주기적으로 다시 읽습니다.
- 로그인은 보통 약 1시간 후 만료됩니다. 데이터가 지워지면 다시 로그인하세요.
- 테이블에서 편집·행 선택·선택 삭제·되돌리기를 사용합니다. 삭제는 추적 상태만 ‘삭제’로 바꾸며 원본 관측 이력은 보존합니다. 즐겨찾기 핀만 이 브라우저에 저장됩니다.

## 수집은 별도
- 기존 Aside 수집이 KST 00:00, 12:00에 계속 시트에 기록합니다.
- GitHub는 수집하지 않으며, 시트나 데이터 파일을 공개하지 않습니다.
- 수집에는 기존 Mac, Aside, 로그인된 브라우저가 필요합니다.
- 00–12 / 12–24는 누적 판매의 관측 구간 차이입니다. 정확한 주문 시각이 아니며, 누락 구간을 추정하지 않습니다.

## 공개되는 것 / 비공개인 것
- 공개: HTML·JavaScript, Google OAuth 클라이언트 ID, 시트 ID, 편집 페이지 URL. 이 ID/URL은 비밀번호가 아니며 접근 권한을 주지 않습니다.
- 비공개: 실제 관측·메모·사용자 열, Google 접근 토큰, 계정 비밀번호.
- 접근 토큰과 Google이 부여한 만료 시각은 현재 탭의 sessionStorage에만 보관하여 새로고침 후 복구합니다. localStorage나 GitHub에는 저장하지 않습니다. 조회 데이터와 편집 초안은 메모리에만 유지합니다. 명시적 로그아웃·인증 만료·401 오류 때 토큰 캐시와 화면을 지웁니다.
- Google 동의 범위는 Sheets 조회·편집(모든 스프레드시트 관리)입니다. 앱 코드는 설정된 시트의 ‘샵목록’ 허용 필드와 새 샵 행을 RAW 값으로 쓰고 결과를 다시 읽어 확인합니다. 새 등록 시 두 시트 대시보드의 빈 ID 슬롯과 고정 샵명 조회 수식도 연결합니다. 과거 관측 행이나 시트 자체를 삭제하지 않습니다. 클라이언트 시크릿·서비스 계정 키·API 키는 사용하지 않습니다.
- 저장소에 실제 시트 데이터, 수집 실행 파일, 인증 JSON, 스크린샷을 업로드하지 마세요.

## 재배포 설정
1. Google Cloud에서 Google Sheets API를 켭니다.
2. Google Auth Platform에서 외부/테스트 앱을 구성하고 시트 소유 계정을 테스트 사용자로 추가합니다.
3. 웹 애플리케이션 OAuth 클라이언트를 만들고 게시 사이트의 HTTPS origin을 승인합니다. 경로 없이 origin만 입력합니다.
4. `config.js`의 공개 클라이언트 ID와 시트 ID를 설정합니다. 시크릿은 넣지 않습니다.
5. 이 폴더의 배포 파일을 저장소 루트에 올리고 Pages를 main 브랜치 / (root)에서 게시합니다.
6. HTML 파일을 직접 열지 말고 게시 주소를 사용합니다. 복사한 다른 도메인은 OAuth 승인 origin도 갱신해야 합니다.

Google 계정·시트 공유 설정은 그대로 유지하세요. 개인정보 안내는 [privacy.html](privacy.html)을 확인하세요.

## 주소
https://magicboard.unlimitedgrowth.xyz/

편집 권한이 추가되어 기존 로그인은 다시 동의해야 할 수 있습니다. 기존 관측 수치와 원자료는 편집 API에서 쓰지 않습니다. 저장 직전 현재 값과 비교하고 저장 후 재조회합니다. Google Sheets 값 API에는 원자적 비교-교환 잠금이 없어 동일 셀을 여러 기기에서 동시에 편집하지 마세요. 샵은 대시보드의 ‘샵 추가’에 Etsy 샵 링크만 넣어 등록합니다. 긴 추적 링크·지역 경로·하위 경로는 샵 메인 URL로 자동 정리하고, 삭제된 샵을 포함한 중복 URL은 거절합니다. 열 추가 등 고급 관리는 기존 편집 페이지를 사용하세요.

## 입력 자동 저장과 로그인 복구
- 메모·카테고리는 입력을 잠깐 멈춘 뒤 자동 저장하고, 칸을 벗어날 때도 저장을 시도합니다. 서버 저장과 재조회를 확인하기 전에는 저장 완료로 표시하지 않습니다.
- 긴 내용은 커서를 올리거나 칸에 초점을 두면 전체 미리보기로 확인합니다. 입력칸에는 스크롤 화살표를 표시하지 않습니다.
- 같은 탭의 새로고침은 Google 접근 토큰의 남은 유효 시간 안에서 로그인 복구가 가능합니다. Google 인증 만료 시간을 연장하거나 영구 로그인을 제공하는 방식은 아닙니다.
- 공용 기기에서는 작업 후 앱 로그아웃을 사용하고 Google 계정도 별도로 로그아웃하세요.

## 샵 추가
- 로그인 후 샵 URL을 붙여넣고 추가를 누릅니다. 쿼리·추적값·언어 경로·하위 경로는 제거합니다. 상품(listing) 링크에서 샵을 추정하지는 않습니다.
- 샵목록에 RAW append로 새 ID/등록 시각만 추가하며 기존 행·관측·메모·사용자 열은 덮어쓰지 않습니다. 누적/리스팅/즐겨찾기는 최초 수집 전까지 미확인입니다.
- 시트 두 대시보드의 비어 있는 ID 슬롯과 고정 샵명 조회 수식만 연결합니다. 새 샵은 다음 정규 수집부터 대상입니다. 여러 기기에서 동시에 같은 샵을 추가하지 마세요(Sheets에는 원자적 중복 제약이 없습니다).
